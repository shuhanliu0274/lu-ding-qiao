# 飞夺泸定桥

以 1935 年 5 月 29 日飞夺泸定桥为背景的约两分钟互动历史短片。体验按序呈现黑屏序章、入场动画、攀索推进、最后冲锋与夺桥结尾。点击或按空格键展示开火；按 N 跳到下一叙事节点。没有分数、升级或失败惩罚。

## 本地运行

在 Windows 上双击 `start-game.bat`，浏览器会打开 `http://127.0.0.1:8767/index.html`。启动脚本使用系统自带的 PowerShell 静态文件服务，无须安装依赖。页面首次点击“开始”后才播放音乐，这是浏览器的音频播放限制。

`index.html` 是正式入口，`play.html` 保留作旧链接兼容。可将同一目录作为静态站点发布；请保持视频、图片、`character/`、`dongzuozhen/` 和 `music/` 的相对路径。

## 素材和声音

入口使用 `enter2 (1).mp4`，桥上背景使用 `background.mp4`，结尾使用 `Video Project.mp4`。主角采用 `character/` 和 `dongzuozhen/` 的 PNG 动作帧，夺桥时使用 `flag.png`。开火时使用 `gun.png` 的火光，不绘制弹道。

`music/` 中的五段 AIFF 分别提供背景音乐、雨声、冲锋号及两种射击声。浏览器不能直接解码 AIFF 时，脚本会在加载阶段把现有 PCM 数据封装为 WAV 并交给 `Audio` 播放；没有合成替代音效。雨声与背景音乐循环叠加，最后冲锋时再播放冲锋号。页面需要通过 HTTP 静态服务打开，直接双击 HTML 文件可能因浏览器限制而无法加载声音。

画面和音效是艺术化的历史表达。角色素材不对应具体历史人物。
